# خطة تنفيذ نظام الإجازات (PTO)

## 📋 نظرة عامة
إضافة نظام إدارة الإجازات والغياب للموظفين، متكامل مع نظام الحجز الحالي.

## 🎯 المتطلبات الأساسية

### أنواع الإجازات
- ✅ إجازة سنوية (Annual Leave)
- ✅ إجازة مرضية (Sick Leave)
- ✅ إجازة شخصية (Personal Leave)
- ✅ إجازة طارئة (Emergency Leave)
- ✅ إجازة بدون راتب (Unpaid Leave)

### سير العمل
1. الموظف يطلب إجازة
2. التيم ليدر يراجع ويعتمد/يرفض
3. الأدمن يرى التقارير والإحصائيات

## 🗄️ بنية البيانات

### جدول الإجازات (vacations)
```javascript
{
  id: "uuid",
  employeeId: "string",
  employeeName: "string",
  type: "annual|sick|personal|emergency|unpaid",
  startDate: "date",
  endDate: "date",
  days: number,
  reason: "string",
  status: "pending|approved|rejected|cancelled",
  requestedAt: "datetime",
  decidedAt: "datetime",
  decidedBy: "string",
  comments: "string"
}
```

### رصيد الإجازات (vacationBalances)
```javascript
{
  employeeId: "string",
  annual: number,      // الرصيد السنوي
  sick: number,        // رصيد المرضي
  personal: number,    // رصيد الشخصي
  usedAnnual: number,  // المستخدم من السنوي
  usedSick: number,    // المستخدم من المرضي
  usedPersonal: number // المستخدم من الشخصي
}
```

## 📱 الشاشات المطلوبة

### 1. شاشة طلب إجازة (للموظف)
- نموذج طلب إجازة
- اختيار نوع الإجازة
- اختيار تاريخ البداية والنهاية
- إدخال السبب
- عرض رصيد الإجازات المتاح
- عرض طلبات الإجازات السابقة

### 2. شاشة مراجعة الإجازات (للتيم ليدر)
- قائمة طلبات الإجازات المعلقة
- قبول/رفض مع تعليق
- عرض التفاصيل الكاملة
- فلترة حسب النوع والتاريخ

### 3. شاشة تقارير الإجازات (للأدمن)
- إحصائيات شاملة
- جدول جميع الإجازات
- تصدير Excel
- فلترة متقدمة
- مقارنة بين الأقسام

## 🔧 التكامل مع النظام الحالي

### الاستفادة من البنية الحالية
- ✅ نفس نظام المصادقة
- ✅ نفس قاعدة البيانات (Supabase)
- ✅ نفس نظام الإشعارات
- ✅ نفس نمط الموافقات (مثل تعديل الحجوزات)
- ✅ نفس تصميم الواجهة

### تعديلات مطلوبة
- إضافة تبويب جديد "Vacations" في شاشة التيم ليدر
- إضافة تبويب جديد "Vacation Reports" في شاشة الأدمن
- إضافة شاشة "My Vacations" للموظف

## 📊 الإحصائيات والتقارير

### الإحصائيات
- عدد الإجازات المعلقة
- عدد الإجازات المعتمدة
- إجمالي أيام الإجازات
- توزيع الإجازات حسب النوع
- مقارنة شهرية/سنوية

### التقارير
- تقرير إجازات الموظف
- تقرير إجازات القسم
- تقرير الإجازات المتداخلة
- تصدير Excel

## 🔐 القواعد والقيود

### قواعد الطلب
- لا يمكن طلب إجازة في الماضي
- لا يمكن طلب إجازة تبدأ اليوم
- الحد الأدنى لطلب الإجازة: يوم واحد
- الحد الأقصى: يحدد من سياسة الشركة

### قواعد الموافقة
- التيم ليدر يوافق/يرفض
- التيم ليدر لا يمكن الموافقة على إجازته الخاصة
- الأدمن يمكن تجاوز القيود

### رصيد الإجازات
- التحقق من الرصيد قبل الموافقة
- خصم الرصيد عند الموافقة
- إعادة الرصيد عند الإلغاء

## ❓ أسئلة للتوضيح

1. **الرصيد الافتراضي:**
   - كم يوم إجازة سنوية؟
   - كم يوم إجازة مرضية؟
   - كم يوم إجازة شخصية؟

2. **السياسات:**
   - هل يحتاج الموظف إشعار مسبق؟
   - كم يوم؟
   - هل يوجد قيود في فترات معينة (مثل رمضان)؟

3. **التقارير:**
   - ما نوع التقارير المطلوبة؟
   - هل تحتاج مقارنة بين الأقسام؟

4. **التكامل:**
   - هل يجب أن يؤثر على الحجوزات؟
   - إذا كان الموظف في إجازة، هل يمنع الحجز؟
