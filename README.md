# Alorica Booking System

نظام حجز مواعيد لشركة **Alorica** مصمم بواجهة عصرية وسهلة الاستخدام.

## المميزات
- **شاشة تسجيل دخول:** مع 3 مستخدمين افتراضيين.
- **نموذج حجز متكامل:** يشمل (Arrival, Departure, Drop off location, Time zone, Calendar).
- **تصدير للبيانات:** إمكانية تصدير بيانات الحجز مباشرة إلى ملف Excel عند الضغط على "Book now".
- **تصميم متجاوب:** يعمل على جميع الأجهزة باستخدام Tailwind CSS.

## التقنيات المستخدمة
- React.js
- Tailwind CSS
- Lucide React (Icons)
- XLSX (Excel Export)
- Babel (للتشغيل المباشر)

## كيفية التشغيل
1. قم بتحميل الملف `index.html`.
2. افتح الملف في أي متصفح ويب.
