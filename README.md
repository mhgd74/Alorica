# Alorica Booking System

نظام حجز مواعيد لشركة **Alorica** مصمم بواجهة عصرية وسهلة الاستخدام.

## المميزات
- **شاشة تسجيل دخول:** مع 3 مستخدمين افتراضيين.
- **نموذج حجز متكامل:** يشمل (Employee Name, Employee ID, Pickup/Drop off location, Time, Time zone, Calendar).
- **صلاحيات المستخدمين:**
  - **المستخدم العادي:** عند الضغط على "Book now" يتم حفظ الحجز فقط (دون تحميل أي ملف).
  - **الأدمن (admin):** يمتلك لوحة إدارة (Admin Dashboard) فيها قسمان:
    - **Bookings:** كل حجوزات الموظفين مجمّعة حسب اليوم مع 3 أزرار:
      1. **Save Excel** — حفظ/تحميل ملف Excel.
      2. **Share** — مشاركة ملف Excel عبر واتساب / تليجرام / ماسنجر / البلوتوث وغيرها.
      3. **Print** — طباعة التقرير مباشرة.
    - **Users:** إنشاء مستخدمين جدد (الاسم الكامل + اسم المستخدم + كلمة المرور) وعرض قائمة المستخدمين الحاليين. تُحفظ الحسابات الجديدة محلياً في المتصفح.
- **ملف Excel:** مقسّم إلى شيتات حسب أيام الشهر، وكل شيت يحتوي على: اسم الموظف، رقم الـ ID، موعد الحجز، نقطة التحميل.
- **حفظ تلقائي:** تُحفظ جميع الحجوزات محلياً في المتصفح (localStorage) حتى يتمكن الأدمن من تصديرها لاحقاً.
- **تصميم متجاوب:** يعمل على جميع الأجهزة باستخدام Tailwind CSS.

## التقنيات المستخدمة
- React.js
- Tailwind CSS
- Lucide (Icons)
- XLSX (Excel Export)
- Babel (للتشغيل المباشر)

## كيفية التشغيل
1. قم بتشغيل السيرفر المحلي: `node server.js`
2. افتح المتصفح على: `http://localhost:3000`

> ملاحظة: تشغيل الموقع عبر HTTP ضروري لعمل ميزة تحديد الموقع (My Location) وميزة المشاركة (Share).
