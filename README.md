# Alorica Booking System

نظام حجز مواعيد النقل لشركة **Alorica** — واجهة عصرية بالإنجليزية بالكامل (LTR)، مع لوحة إدارة كاملة وتوزيع تلقائي على الباصات وتقارير Excel قابلة للمشاركة والطباعة.

## المميزات

- **شاشة تسجيل دخول** بحسابات النظام (لا تظهر بيانات الدخول في الواجهة).
- **نموذج حجز متكامل:** اسم الموظف، رقم الـ ID، Pickup/Drop off location، اختيار الساعة والدقيقة، المنطقة الزمنية، والتقويم (يمنع التواريخ الماضية).
  - زر **My Location** لتعبئة الموقع من الـ GPS.
  - منع الحجز المكرر (نفس الموظف + نفس التاريخ + نفس الوقت + نفس النوع).
- **تبويبا Arrival / Departure** أعلى منتصف الشاشة.
- **الصلاحيات:**
  - **المستخدم العادي:** زر `Book now` يحفظ الحجز فقط.
  - **الأدمن (`admin`):** لوحة إدارة بثلاث تبويبات:

### 1) Bookings
- بطاقات إحصائية: عدد الحجوزات / الأيام / الموظفين / قائمة الانتظار.
- **بحث وفلترة**: بحث نصي (اسم، ID، نقطة، باص) + نطاق تاريخ (From / To) + زر Clear filters. كل عمليات التصدير تعمل على النتائج المفلترة.
- **جدول الحجوزات** مجمّعاً حسب اليوم مع إمكانية:
  - تغيير باص أي حجز يدوياً من قائمة منسدلة (يُعلَّم كتعيين يدوي).
  - حذف أي حجز.
- **ثلاثة أزرار:**
  1. **Save Excel** — تنزيل ملف Excel.
  2. **Share** — مشاركة ملف Excel عبر مشاركة النظام (واتساب / تليجرام / ماسنجر / بلوتوث...).
  3. **Print** — طباعة التقرير مباشرة (صفحة لكل يوم).
- أزرار إضافية: **WhatsApp summary**، **Telegram summary**، **Copy summary** لمشاركة نصية سريعة.
- زر **Auto-assign buses** لإعادة التوزيع التلقائي.

### 2) Buses
- إضافة / حذف باصات وتعديل سعة كل باص (عدد المقاعد في اليوم).
- **توزيع تلقائي**: تُملأ الباصات بالترتيب حسب موعد الحجز، ومن لا يجد مكاناً ينتقل إلى **Waitlist** ويظهر بالأحمر.
- إحصائيات: إجمالي المقاعد يومياً وعدد من في قائمة الانتظار.

### 3) Users
- إنشاء مستخدمين جدد (الاسم + اسم المستخدم + كلمة المرور) مع منع تكرار اسم المستخدم. الحسابات الجديدة بصلاحية «مستخدم عادي».
- **Data Backup & Restore** — تصدير/استيراد نسخة JSON تحتوي الحجوزات والباصات والمستخدمين.

## ملف Excel
- شيت **Summary** أولاً: ملخص لكل يوم (عدد الحجوزات، الموظفين، توزيع الباصات، قائمة الانتظار) + صف إجمالي.
- ثم **شيت لكل يوم** يحتوي: Employee Name، Employee ID، Booking Time، Pickup Point، Type، **Bus**.
- ترويسة ملوّنة بألوان Alorica، صف إجمالي، **AutoFilter**، وأعمدة بعروض مناسبة.
- اسم الملف: `Alorica_Bookings_<date>.xlsx` أو `Alorica_Bookings_<from>_to_<to>.xlsx` عند تطبيق فلتر تاريخ.

## التشغيل
1. `node server.js`
2. افتح: `http://localhost:3000`

> Geolocation ومشاركة الملفات تحتاج HTTP/HTTPS (لا تعمل عبر `file://`).

## العمل دون إنترنت (Offline / PWA)
جميع المكتبات مستضافة محلياً في `vendor/` (React، Babel، Tailwind، Lucide، xlsx-js-style) وليس عبر CDN، إضافة إلى `manifest.json` و `sw.js` لتفعيل العمل دون اتصال والتثبيت على الجهاز بعد أول زيارة.

## التقنيات
React 18 (UMD) · Babel Standalone · Tailwind CSS · Lucide · xlsx-js-style · Node.js HTTP server · localStorage.

## بنية الملفات
```
index.html      # التطبيق كامل (React + Babel داخل المتصفح)
server.js       # سيرفر محلي على المنفذ 3000
manifest.json   # بيانات PWA
sw.js           # Service Worker للتخزين المؤقت
logo.png        # شعار Alorica
vendor/         # المكتبات المستضافة محلياً
```
